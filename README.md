# IOTClassReview

IoT 수업에서 배운 내용을 정리하는 저장소입니다. 정리한 글은 저장소의 파일이 아니라 [Issues](https://github.com/inha20/IOTClassReview/issues)에 있으며, 대부분의 이슈가 한 주차 분량입니다.

## 참고

- 이슈는 2025년 3월 11일부터 2025년 5월 3일 사이에 작성되었습니다.
- 이슈 번호와 주차 번호는 같지 않습니다. `#1`부터 `#6`까지는 번호보다 주차가 1 큰 값이고(`#1`이 2주차), `#7`은 9주차입니다. 8주차라는 제목의 이슈는 없습니다.
- 위 표의 "다루는 내용"은 각 이슈의 제목과 본문 주제를 간단히 옮긴 것이며, 자세한 내용은 이슈 본문을 확인하면 됩니다.
